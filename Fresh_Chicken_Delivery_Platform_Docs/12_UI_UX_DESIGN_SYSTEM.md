# UI/UX & Design System

---

## 1. Brand Direction

Brand:
**Fresh Chicken**

Style:
**Minimal luxury**

Avoid:
- Generic red/yellow fast-food palette.
- Cartoon chicken mascot.
- Excessive gradients.
- Overloaded cards.
- Cheap marketplace appearance.

Aim for:
- Premium typography.
- Warm neutral tones.
- High-quality food photography.
- Controlled spacing.
- Subtle borders.
- Strong hierarchy.
- Clean micro-interactions.

---

## 2. Suggested Palette

Use a restrained palette and validate with actual logo/photography.

Base:
- Warm ivory/off-white.
- Charcoal.
- Deep neutral.
- Muted natural accent.
- Soft beige/taupe.

CTA can use one strong brand accent.

Do not use many competing colors.

---

## 3. Typography

Use a premium modern sans-serif for UI.

Optional editorial serif for selected headings if it improves the brand.

Typography hierarchy:
```text
Hero
H1
H2
H3
Body
Caption
Price
```

---

## 4. Components

Build reusable:
- Button.
- Input.
- Select.
- Product card.
- Price display.
- Badge.
- Availability badge.
- Cart item.
- Modal.
- Drawer.
- Toast.
- Stepper.
- Order timeline.
- Map panel.
- Admin table.
- Admin metric card.

---

## 5. Customer Layout

Mobile:
- Bottom navigation or compact navigation if justified.
- Sticky cart/checkout CTA.
- Large product imagery.
- Easy location access.

Desktop:
- Max-width content container.
- Clean navigation.
- Strong hero.
- Product grids.

---

## 6. Admin Layout

Desktop-first but responsive.

```text
Sidebar
  +
Topbar
  +
Main workspace
```

Tables should support:
- Search.
- Filters.
- Sort.
- Pagination.

---

## 7. Delivery Layout

Mobile-first.

Primary actions should be obvious:
- Navigate.
- Call/contact.
- Start delivery.
- Mark delivered.

Avoid unnecessary analytics.

---

## 8. States

Every screen must design:
- Loading.
- Empty.
- Error.
- Success.
- Disabled.
- Offline/poor connection where relevant.

---

## 9. Accessibility

- Semantic HTML.
- Keyboard navigation.
- Focus states.
- Proper labels.
- Color is not the only status signal.
- Sufficient contrast.
- Reduced motion support.

---

## 10. Motion

Use subtle:
- Page transitions.
- Product image transitions.
- Cart confirmation.
- Order status progress.

Never use animation that delays basic tasks.
